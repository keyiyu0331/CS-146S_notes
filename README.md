# CS146S

Coursework for Stanford's CS146S: working code and markdown notes summarizing concepts covered each week.

## Layout

- `code/weekN/` — code written or given for week N.
- `notes/weekN.md` — a markdown summary of the concepts covered in week N.
- `requirements.txt` — Python dependencies shared across all weeks' code.

See `CLAUDE.md` for the full conventions.
